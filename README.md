# SkillGenome AI — Overview

SkillGenome AI is a futuristic AI-powered developer intelligence platform designed to analyze, track, and predict a developer’s growth journey using advanced analytics, AI systems, and real-time skill evaluation.

The platform creates a unique “Developer DNA” profile by analyzing:
- coding skills,
- GitHub activity,
- DSA performance,
- projects,
- learning consistency,
- AI readiness,
- and technical growth patterns.

Using AI, SkillGenome generates:
- personalized career roadmaps,
- salary predictions,
- hiring probability analysis,
- skill evolution tracking,
- weakness detection,
- and intelligent career insights.

========================================
GLOBAL SALARY INTELLIGENCE
========================================

SkillGenome AI includes an advanced localization-based salary engine that:
- auto-detects user country,
- adapts currency automatically,
- and shows localized salary formats.

Examples:
- India → ₹ LPA
- USA → USD $
- UK → GBP £
- Europe → EUR €
- Japan → JPY ¥

The system also provides:
- market demand analysis,
- region-based salary forecasts,
- and country-specific career insights.
